# Email Retention Alert System (ระบบติดตามและแจ้งเตือนเมลพนักงานลาออกครบ 3 เดือน)

ระบบอัตโนมัติ 2 ชีต ทำงานร่วมกับ **LINE Official Account (LINE OA)** และ **Google Sheets** รองรับการพิมพ์แจ้งลาออกจากในกลุ่ม LINE เพื่อเปลี่ยนสถานะเมลเป็น `Inactive` ทันที พร้อมระบบยกเลิกลาออก เช็คสถานะรายบุคคล และสรุปรายการที่ครบกำหนดในเดือนปัจจุบัน

---

| ฟังก์ชัน | ตัวอย่างคำสั่งที่พิมพ์ในแชต | คำอธิบายการทำงาน |
| :--- | :--- | :--- |
| **1. แจ้งลาออก** | `สมชาย มีกำหนด ลาออก 08/12/2026`<br>`Aknarin มีกำหนด ลาออก 07/10/2026`<br>`แจ้งลาออก สมชาย 08/12/2026` | ค้นหาพนักงาน ➡️ ปรับเมลเป็น `Inactive` ➡️ คำนวณวันครบกำหนด 3 เดือน ➡️ บันทึกเข้าชีตคิว ➡️ ส่งการ์ดสีเขียวยืนยัน |
| **2. ยกเลิกลาออก** | `ยกเลิก สมชาย`<br>`ยกเลิกลาออก สมชาย`<br>`ยกเลิก it.officer@regent-chaam.com` | คืนสถานะเมลกลับเป็น `Active` ทันที ➡️ ปรับสถานะในคิวลาออกเป็น `Cancelled` ➡️ ส่งการ์ดสีเขียวมิ้นต์ยืนยัน |

| **4. ครบกำหนดในเดือนนี้** | `กำหนดในเดือนนี้มีใครบ้าง`<br>`ครบกำหนดเดือนนี้` | สรุปรายชื่อเมลพนักงานทั้งหมดที่ครบกำหนดจัดการในเดือนปัจจุบัน พร้อมแสดงอีเมลและวันครบกำหนด |

## 🚀 วิธีอัปเดตโค้ดล่าสุดเข้า Google Apps Script

1. คัดลอกโค้ดทั้งหมดจาก [`Code.gs`](file:///D:/Ann/email-reminder/Code.gs) ไปวางทับใน Apps Script
2. กด **บันทึก (Ctrl + S)**
3. คลิก **ทำให้ใช้งานได้ (Deploy)** > **จัดการการทำให้ใช้งานได้ (Manage deployments)**
4. คลิกไอคอนรูปดินสอ ✏️ (แก้ไข) ➡️ ตรงช่อง **เวอร์ชัน (Version)** ให้เลือก 👉 **เวอร์ชันใหม่ (New version)** แล้วกด **ทำให้ใช้งานได้ (Deploy)**
5. ทดลองพิมพ์คำว่า **`เมนู`** ในแชต LINE เพื่อเริ่มใช้งานได้ทันทีค่ะ!
